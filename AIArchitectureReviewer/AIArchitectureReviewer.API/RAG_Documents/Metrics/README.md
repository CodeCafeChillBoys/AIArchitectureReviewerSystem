# Metrics — Tổng quan

Thư mục này chứa các tài liệu mô tả những metric quan trọng khi đánh giá kiến trúc, chất lượng code, và khả năng bảo trì hệ thống.

## Mục lục
- Coupling — `coupling.md`
- Cohesion — `cohesion.md`
- Complexity — `complexity.md`
- Maintainability — `maintainability.md`

## Cách dùng
- Mở từng file để xem định nghĩa, dấu hiệu, tác động, ví dụ, và checklist.
- Dùng như tài liệu hỗ trợ code review, thiết kế kiến trúc, và refactoring.
- Các metric này nên được đọc cùng nhau vì chúng thường liên quan chặt chẽ.

Mục tiêu của thư mục này là giúp bạn nhận diện sớm rủi ro thiết kế trước khi chúng trở thành chi phí bảo trì lớn.
