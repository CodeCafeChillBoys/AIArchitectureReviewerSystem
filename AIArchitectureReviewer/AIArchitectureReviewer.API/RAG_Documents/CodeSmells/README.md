# Code Smells — Tổng quan

Thư mục này chứa các tài liệu mô tả những code smell phổ biến, cách nhận diện, tác hại, nguyên nhân thường gặp, và hướng xử lý.

## Mục lục
- God Class — `god_class.md`
- Feature Envy — `feature_envy.md`
- Data Clumps — `data_clumps.md`
- Shotgun Surgery — `shotgun_surgery.md`
- Duplicated Code — `duplicated_code.md`
- Cyclic Dependency — `cyclic_dependency.md`

## Cách dùng
- Mở từng file để xem mô tả, dấu hiệu nhận biết, rủi ro, ví dụ, và checklist.
- Dùng như tài liệu review code hoặc checklist refactoring.
- Mỗi file tập trung vào một smell riêng để dễ đối chiếu khi đọc code.

Mục tiêu của thư mục này là giúp nhận diện sớm các mùi thiết kế trước khi chúng làm hệ thống khó bảo trì, khó test, hoặc khó thay đổi.
