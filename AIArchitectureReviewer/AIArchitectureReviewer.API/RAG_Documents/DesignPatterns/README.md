# Design Patterns — Tổng quan

Thư mục này chứa các ghi chú tham khảo chi tiết cho những design pattern phổ biến thuộc nhóm Creational, Structural, và Behavioral.

## File hiện có
- singleton.md
- factory.md
- abstract_factory.md
- builder.md
- strategy.md
- observer.md
- decorator.md
- adapter.md
- command.md
- template_method.md
- facade.md

## Cách dùng
- Mở từng file để xem mô tả, cấu trúc tham gia, ví dụ Python, ưu nhược điểm và checklist.
- `factory.md` tập trung vào Factory Method.
- `abstract_factory.md` tập trung vào Abstract Factory.
- Các file còn lại mô tả từng pattern riêng lẻ theo cùng một khung nội dung.

Mở file tương ứng để tra cứu chi tiết và đối chiếu nhanh khi thiết kế hoặc review code.
