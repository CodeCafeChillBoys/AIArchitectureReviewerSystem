# Database — Tổng quan

Thư mục này chứa các tài liệu về thiết kế dữ liệu và pattern truy cập dữ liệu, bao gồm normalization, ERD (Entity-Relationship Diagram), và Repository pattern.

## Mục lục
- Normalization — `normalization.md`
- ERD (Entity-Relationship Diagram) — `erd.md`
- Repository Pattern — `repository_pattern.md`

## Cách dùng
- Mở từng file để xem định nghĩa, ví dụ, checklist và best practices.
- Dùng chúng khi thiết kế schema, review data model, hoặc khi xây lớp truy cập dữ liệu (repositories/DAOs).
